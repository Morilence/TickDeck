- (decision) Persistence deployment decision overridden and accepted: SQLite is the sole transactional database for all current local and remote-self-host profiles, and every TickDeck process MUST run on one host. - (decision) Artifact persistence split accepted: SQLite is authoritative for domain state, configuration, jobs, leases, policy decisions, audit, outbox, and Artifact Manifests. Immutable datasets, run outputs, report attachments, and other large artifacts live in a same-host content-addressed filesystem store. Each manifest records digest, size, media/schema version, sensitivity, and retention metadata. Writes use controlled staging, verification, durable flush, and atomic promotion; only verified objects may become authoritative references. Connectors, sidecars, and sandboxes access artifacts only through granted Artifact Store operations, never arbitrary paths. No S3, NAS, or remote object-store implementation is authorized. Secrets never enter artifacts or default backups.
- (decision) Consistency spine accepted: every authoritative command is committed by the control plane in one serialized SQLite write transaction that validates state version/Gate/authorization, reserves a unique operation_id and idempotency key, updates domain state, appends immutable audit, and appends the outbox/job. External effects never occur inside the transaction. Workers execute only committed leased operations and return results through the control plane, which records outcome/state/audit atomically. Duplicate simulation orders are prevented by database unique constraints. Pre-commit crashes leave no operation; post-commit/pre-dispatch crashes resume from outbox; post-effect/pre-ack ambiguity becomes explicit uncertain state and is never blindly retried. Delivery may repeat, effects may not.
- (decision) R2 non-replay protocol accepted: each confirmation creates a server-side single-use opaque Grant whose stored hash is bound to protected session/subject, workspace, action/tool, canonical full-parameter digest, authoritative state version, DataUsePolicy and EgressPolicy digests, nonce, issuance/expiry, and max_uses=1. In one BEGIN IMMEDIATE transaction the control plane validates and conditionally consumes the Grant, then creates exactly one operation, audit record, and outbox entry. Refresh, double-click, concurrent tabs, and transport retries cannot create another operation. A committed Grant stays consumed on failure; outbox recovery may only continue that same immutable operation. Post-effect ambiguity becomes UNCERTAIN and is never automatically invoked again; a genuinely new attempt requires fresh state validation and a new explicit R2 confirmation. Grant material is excluded from URLs, ordinary logs, artifacts, and notification bodies.
- (decision) Recovery contract accepted: every run persists an immutable frozen RunContext before queueing. Workers receive expiring leases with monotonically increasing fencing epochs and heartbeats; stale workers cannot commit. Replay-safe pure computation/sandbox work may be requeued under the same operation with a new attempt and the identical context. Before any external effect the control plane durably marks DISPATCHING; a crash after that boundary without confirmed outcome yields UNCERTAIN and forbids automatic re-invocation. Cancellation is persisted first, then signaled, and watchdog termination yields INTERRUPTED. Partial artifact staging never becomes authoritative and is verified/quarantined/cleaned during recovery. Browser/session disconnect never cancels durable work. Canonical states are QUEUED, LEASED, RUNNING, SUCCEEDED, FAILED, CANCELED, INTERRUPTED, and UNCERTAIN, with explicit recovery attempt provenance shown to UX.
- (decision) Protected session model accepted without users/orgs/RBAC. Local mode binds loopback and uses a non-logged single-use bootstrap secret delivered by launcher/interactive terminal to establish a server-side opaque session; localhost alone is never trust. Remote mode uses one workspace administration secret over HTTPS or an explicitly trusted reverse proxy, accepts forwarded identity/headers only from exact configured proxy addresses, and prevents direct upstream-port bypass. Browser holds a high-entropy host-only HttpOnly SameSite=Strict session token (Secure remotely); SQLite stores only its hash, subject, expiry, and revocation. Mutations validate session, CSRF, Host, and Origin; Host allowlists prevent DNS rebinding; WebSockets require origin validation and a short-lived single-use connection ticket. Sessions have idle/absolute expiry and revocation. Session/bootstrap/CSRF secrets are excluded from logs, artifacts, notifications, and default backups. Session loss never silently cancels durable runs.
- (decision) DataUsePolicy model accepted: a versioned declarative server-side compiler combines connector authorization purpose/expiry, deployment-use scope, data category, and requested action into ALLOW or DENY with machine-readable reasons. Unknown values, conflicts, unverifiable provenance, and expired authorization default deny. Restrictions propagate by most-restrictive intersection through derived data, indexes, backtests, reports, model context, exports, and backups; processing cannot wash away license constraints. Each run records policy version and decision digest, and execution re-evaluates against current authoritative state. Models/extensions/connectors may only tighten policy. A durable asset inventory records provenance, lineage, expiry, and downstream references; revocation/expiry drives cleanup or quarantine and marks affected artifacts not fully reproducible. Audit retains policy evidence without retaining forbidden payload. No executable policy scripts are allowed.
- (decision) EgressPolicy model accepted: all model, webhook, custom-endpoint, and external data-connector traffic must cross the trusted Worker Egress Gateway; other control-plane/worker modules, connectors, and sandboxes may not create arbitrary external sockets. Dispatch requires current DataUsePolicy, exact scheme/host/port allowlist, field minimization, endpoint-scoped credentials, request/byte/time/cost budgets, risk, and authorization. Resolution rejects loopback/private/link-local/reserved/cloud-metadata addresses by default, dials the validated address to close DNS-rebinding TOCTOU, and revalidates every explicitly permitted bounded redirect. Credentials are injected only after destination validation and never forwarded across host changes. Narrow operator-approved internal-target exceptions require explicit risk disclosure; new external data recipients require R2. Responses remain untrusted data. Audit records destination/resolved address/data classes/size/budget/decision without secrets or restricted payload. Trusted SDK sidecars must use the supported gateway/proxy path and pass bypass conformance tests. Authenticated same-host IPC is a distinct non-egress channel.
- (decision) Secret lifecycle accepted with UX clarification. - (decision) Backup/restore model accepted: a versioned workspace bundle is built from a consistent SQLite logical snapshot while referenced immutable artifacts are pinned.
